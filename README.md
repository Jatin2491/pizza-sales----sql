# Pizza Sales SQL Analysis 🍕

## Overview
This project analyzes pizza sales data using SQL.

## Dataset
- Orders
- Order Details
- Pizzas
- Pizza Types

## Questions Solved
- Total number of orders
- Total revenue
- Most ordered pizza
- Top 5 pizzas
- Category-wise analysis
- Revenue trends

## Tools Used
- MySQL / PostgreSQL
- SQL Joins, Aggregations, Window Functions

## How to Run
1. Import dataset
2. Run schema.sql
3. Execute queries.sql
